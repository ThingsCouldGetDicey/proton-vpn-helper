Automatic region detection

A built-in controller detects explicit region restrictions and asks the Proton connection engine to select a permitted country.

How learning works

If a page clearly refuses access because of location, the router can try eligible Proton exit countries. It remembers a candidate only after a successful HTTP response and a substantial page without the detected block.

This is a heuristic, not a promise that every site or age-check requirement can be bypassed. The website may still require verification. No identity documents or page text are stored.

MCP-ready rules

The routing policy is local, versioned and validated. Updates can be applied without changing your existing Proton account or editing the official extension.
